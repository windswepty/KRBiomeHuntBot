# 🏹 한바헌봇 (KRBiomeHuntBot)

디스코드 서버를 위한 **포인트 이코노미 & 포상 시스템 디스코드 봇**입니다.  
유저들의 서버 활동(채팅, 출석 등)을 통해 포인트를 적립하고, 포인트 상점에서 다양한 혜택을 이용할 수 있습니다.

---

## ✨ 주요 기능

### 1. 📅 일일 출석체크 (`/출석`)
- 하루에 한 번 출석체크를 진행하고 **+100 포인트**를 획득합니다.
- 한국 시간(KST) 매일 00:00 기준으로 출석 기록이 리셋됩니다.

### 2. 💬 채팅 활동 자동 적립
- 서버 텍스트 채널에서 메시지 **10회** 작성 시마다 **+5 포인트**가 자동으로 적립됩니다.
- **스팸 방지 필터링**:
  - 사진 / 첨부파일 / 스티커 제외
  - 단독 이모티콘 및 GIF 링크 (Tenor, Giphy 등) 제외

### 3. 💳 포인트 조회 & 가이드 (`/포인트확인`, `/포인트얻는법`)
- 현재 나의 보유 포인트를 한눈에 확인할 수 있습니다.
- 대화형 드롭다운 메뉴를 통해 포인트 획득 방법에 관한 안내를 확인할 수 있습니다.

### 4. 🛒 포인트 상점 (`/포인트상점`)
- 적립한 포인트로 상품이나 특별 혜택을 구매할 수 있는 상점 시스템입니다.

### 5. 🔒 비공개 응답 (Ephemeral)
- 개인 정보 보호 및 채팅방 도배 방지를 위해 모든 명령어 응답은 **명령어를 입력한 유저 본인에게만** 보이도록 설정되어 있습니다.

### 6. ☁️ 클라우드 데이터베이스 (MongoDB)
- MongoDB Atlas 클라우드 DB 연동으로 봇 재배포 및 서버 재시작 시에도 포인트 데이터가 **영구 보존**됩니다. (DB 연결 불가 시 로컬 JSON 자동 폴백)

## 📜 슬래시 명령어 목록

| 명령어 | 설명 |
| :--- | :--- |
| `/출석` | 하루 한 번 출석체크를 진행하고 100포인트를 획득합니다. |
| `/포인트확인` | 내가 현재 보유한 총 포인트를 확인합니다. |
| `/포인트얻는법` | 포인트 획득 방법과 안내 도움말을 드롭다운으로 확인합니다. |
| `/포인트상점` | 포인트 상점 항목 및 구매 내역을 확인합니다. |

---

## 🛠️ 기술 스택 (Tech Stack)

- **Language**: Python 3.10+
- **Library**: `discord.py` (Cogs & Slash Commands)
- **Database**: MongoDB Atlas (`pymongo`), Local JSON Fallback
- **Hosting / Deployment**: Render (`render.yaml`), `keep_alive` Flask Server
