# 🏹 한바헌봇 (KRBiomeHuntBot)

디스코드 서버를 위한 **포인트 이코노미 & 포상 시스템 디스코드 봇**입니다.
유저들의 서버 활동(채팅, 출석, 희귀 바이옴 제보 등)으로 포인트를 적립하고,
포인트 상점과 럭키 뽑기에서 상품 · 역할을 획득할 수 있습니다.

---

## 📜 슬래시 명령어 목록 (총 18개)

| 명령어 | 설명 |
| :--- | :--- |
| `/출석` | 하루 한 번 출석체크를 진행하고 **+100 P**를 획득합니다. |

## ✨ 주요 기능

### 1. 📅 일일 출석체크 (`/출석`)
- 하루 한 번 출석체크로 **+100 포인트** 획득
- 한국 시간(KST) 매일 **00:00** 기준으로 출석 기록 리셋

### 2. 💬 채팅 활동 자동 적립 (명령어 없음 · 자동 동작)
- 서버 텍스트 채널에서 메시지 **10회**마다 **+10 포인트** 자동 적립 (일일 상한 없음)
- **스팸 방지 필터링**
  - 사진 / 첨부파일 / 스티커 메시지 제외
  - GIF 링크(Tenor, Giphy, Gfycat, `.gif`, `.gifv`) 제외
  - URL · 커스텀 이모지 · 유니코드 이모지를 제거한 뒤 **내용이 남지 않으면 카운트 제외**
- 블랙리스트 등록 유저는 적립 대상에서 제외

### 3. ⚡ 게릴라 채널 부스트 (`/채널부스트`)
- 특정 채널에 **포인트 배율**(2배, 3.5배 등 1.0 이상)을 적용해 한시적 이벤트 개최
- 기간 입력은 `10s`, `30m`, `1h`, `2d` 및 `30분`, `1시간`, `2일` 형식 지원 (**최소 10초**, `0` 입력 시 무제한)
- **5초 주기 백그라운드 루프**가 만료를 감시해 자동 해제하고, 해당 채널에 종료 안내 임베드를 발송
- 진행 중인 부스트 목록(채널 · 배율 · 남은 시간) 확인 및 즉시 수동 해제 지원

### 4. 🛒 포인트 상점 (`/상점`, `/상점설정`)
- 포인트로 상품 · 혜택 구매, 구매 시 **디스코드 역할 자동 지급** 가능
- 재고 관리 지원 (`-1` = 무제한, `0` = 품절 처리 및 구매 차단)
- 관리자는 드롭다운 UI로 상품 추가 / 재고 충전 / 삭제 / 목록 확인

### 5. 🎰 럭키 뽑기 (`/뽑기`, `/뽑기설정`)
- 포인트를 소비해 확률 추첨, 당첨 시 **역할 + 포인트 보상** 동시 지급 가능
- **전체 항목의 확률 합이 정확히 100%가 아니면 뽑기 실행 자체가 차단**되어 설정 실수를 방지
- 항목별 재고 관리 및 당첨 시 자동 차감

### 6. 🎫 희귀 바이옴 제보 티켓 (`/제보`, `/제보설정`)
- 채널 링크 · 규칙 동의 모달 제출 시 **제보자와 관리자만 볼 수 있는 비공개 티켓 채널** 자동 생성
- 티켓 생성 시 지정된 **알림 역할 멘션**으로 관리자 호출
- 관리자가 [💰 포인트 지급] 버튼 클릭 시 설정된 기본 포인트(기본값 **500 P**) 지급 후 **버튼 비활성화로 중복 지급 차단**
- [❌ 티켓 닫기] → 유저 권한 제외 및 채널명 변경 → [🗑️ 티켓 삭제]의 **2단계 삭제 절차**
- 버튼은 `timeout=None` 영구 View라 봇 재시작 후에도 정상 동작

### 7. 🚫 포인트 블랙리스트 (`/블랙리스트`)
- 매크로 · 파밍 등 어뷰징 유저를 **포인트 적립 대상에서 제외**
- 버튼 UI로 추가 / 해제 / 목록 새로고침, 등록 사유 기록 지원

### 8. 📋 활동 로그 (`/로그`)
- `🛒 상점 구매` · `🎰 뽑기 당첨` · `🎫 바이옴 제보` · `🛠️ 관리자 조정` 카테고리별 조회
- 페이지당 10건, 최대 5페이지(50건)까지 페이지 이동 버튼으로 열람

### 9. 🔒 비공개 응답 (Ephemeral)
- 개인정보 보호 및 채팅방 도배 방지를 위해 모든 명령어 응답은 **명령어를 입력한 본인에게만** 표시

### 10. 🎛️ 시스템 전원 스위치 (`/인증시스템`)
> 문제가 생겼을 때 **즉시 정지**할 수 있는 비상 스위치입니다. 봇 재시작이 필요 없습니다.

- 인증 · 링크 보호의 현재 상태를 한눈에 보여주고, 버튼으로 각각 또는 한 번에 켜고 끕니다.
- **[🛑 전체 끄기]** 를 누르면 봇이 웹훅 임베드를 전혀 건드리지 않고 인증 버튼도 응답하지 않아,
  **기능이 설치되지 않은 상태와 동일**해집니다.
- 설정은 메모리 캐시에 즉시 반영되므로 **누르는 순간 적용**됩니다.
- 정지 중에는 **이미 게시된 보호 메시지의 버튼도 누구나** 링크를 받습니다.
  정지 상태에서 유저가 링크를 못 받는 일이 없도록, 역할 검사보다 전원 검사를 먼저 수행합니다.
  (이때는 워터마크와 열람 기록도 남기지 않습니다)

> ⚠️ **인증만 끄면 안 됩니다.** 인증을 끄고 링크 보호를 켜두면
> 아직 인증받지 못한 유저가 **인증받을 방법이 없어 링크에 영영 접근하지 못합니다.**
> 평상시 상태로 되돌리려면 반드시 **[🛑 전체 끄기]** 를 사용하세요.
> 이 조합이 되면 `/인증시스템` 화면에 경고가 표시됩니다.

> ℹ️ **되돌릴 수 없는 것 하나**: 정지 이전에 이미 치환된 메시지는 원본으로 복구되지 않습니다.
> 원본 웹훅 메시지는 삭제된 상태이기 때문입니다. 다만 버튼은 누구나 누를 수 있으므로 접근에는 문제가 없습니다.

> ✅ **처음 배포해도 안전합니다**: 보호 채널 목록과 인증 역할이 비어 있는 상태에서는
> 감지 대상도, 인증 패널도 없어 봇이 아무것도 건드리지 않습니다. 설정을 마친 뒤부터 동작합니다.

### 11. 🔐 서버 인증 (`/인증설정`)
> 이 기능은 **포인트 시스템과 완전히 분리된 독립 모듈**입니다. 포인트가 오가지 않고 활동 로그에도 기록되지 않습니다.

- 인증 채널에 전송된 패널의 **[✅ 인증하기] 버튼 클릭 즉시** 지정된 인증 역할이 부여됩니다.
- 패널 제목 · 안내 문구 · 버튼 문구를 관리자가 자유롭게 수정할 수 있습니다.
- 이미 인증된 유저, 역할 미설정, **봇 역할이 인증 역할보다 아래인 경우** 등 실패 원인을 각각 안내합니다.
- `현재 설정 확인`에서 역할 관리 권한과 역할 서열까지 자동 점검합니다.
- 버튼은 고정 `custom_id`의 영구 View라 **봇 재시작 후에도 그대로 동작**합니다.

### 12. 🎮 로블록스 개인서버 링크 보호 (`/링크보호설정`)
> 이 기능도 포인트 시스템과 무관하게 동작하는 **독립 모듈**입니다.
> **로블록스 개인서버(Private Server) 링크**를 인증 유저 전용으로 배포하는 데 최적화되어 있습니다.

지정한 채널에 **웹훅**이 임베드를 올리면, 봇이 이를 감지해 다음과 같이 치환합니다.

```
[원본 웹훅 임베드]                       [봇이 치환한 임베드]
🎮 개인서버 오픈!                        🎮 개인서버 오픈!
roblox.com/games/...?privateServer  →   `🔒 인증된 유저만 입장할 수 있습니다`
                                          ┌──────────────────┐
                                          │ 🎮 개인서버 입장하기 │ ← 클릭 시 역할 검사
                                          └──────────────────┘
```

**📂 감시 대상 지정 — 카테고리 단위 (권장)**

`/링크보호설정` → **감시 카테고리 추가**로 카테고리를 지정하면,
그 안의 **모든 텍스트 채널(비공개 포함)** 이 한 번에 감시 대상이 됩니다.

- 카테고리를 여러 개(최대 25개씩) 한 번에 선택할 수 있습니다.
- 카테고리에 **채널을 새로 만들면 자동으로 감시 대상에 포함**됩니다. 재설정이 필요 없습니다.
- 카테고리 밖의 채널은 **개별 채널 추가**로 따로 지정할 수 있습니다.
- 스레드에 올라온 웹훅 임베드는 **부모 채널 기준**으로 판정합니다.

> ⚠️ **비공개 채널 주의**: 봇이 채널을 못 보면 메시지 자체가 오지 않아 감시가 되지 않습니다.
> 비공개 채널은 채널 권한 설정에 **봇 역할을 추가**해 주세요.
> `현재 설정 및 권한 점검`에서 권한이 부족한 채널을 자동으로 찾아 알려줍니다.

- **감지 대상은 웹훅 메시지 뿐입니다** (`webhook_id` 기준). 일반 유저와 봇 자신의 메시지는 건드리지 않습니다.
- 링크가 들어올 수 있는 **세 곳을 모두** 훑습니다. 매크로마다 링크를 담는 위치가 다르기 때문입니다.

| 매크로 유형 | 링크 위치 | 처리 |
| :--- | :--- | :--- |
| maxstellar's Biome Macro | 임베드 본문의 평문 URL | 잠금 문구로 치환 |
| Coteab Macro | 마크다운 마스킹 링크 `[Join Server](url)` | 문구만 남기고 URL 제거 |
| MultiScope | **[Join Server] 링크 버튼(컴포넌트)** | 버튼째 제거 후 보호 버튼으로 교체 |

- 임베드의 **제목 하이퍼링크 · 본문 · 필드 · 작성자 링크**와 **메시지 본문**, **링크 버튼**에서 URL을 모두 추출합니다.
- 컴포넌트는 중첩될 수 있어 재귀적으로 탐색하므로, 버튼이 여러 겹으로 감싸여 있어도 놓치지 않습니다.
- **이미지 · 썸네일 URL은 그대로 보존**되어 임베드 모양이 깨지지 않습니다.
- 링크가 하나도 없는 임베드는 **원본을 그대로 둡니다**.
- 원본은 삭제 후 재게시되며, 누가 보냈는지 알 수 있도록 **원본 웹훅의 이름 · 프로필이 임베드 작성자란에 유지**됩니다.

#### ⚡ 속도 설계 (수백 명 동시 클릭 대비)

개인서버는 자리 경쟁이 벌어지므로, 버튼 클릭부터 입장까지의 지연을 최소화했습니다.

| 처리 단계 | 방식 |
| :--- | :--- |
| 링크 조회 | **메모리 캐시** (봇 재시작 후 첫 클릭만 DB 조회) |
| 인증 설정 조회 | **메모리 캐시** (저장 시 즉시 갱신되어 값이 어긋나지 않음) |
| 역할 검사 | 이미 메모리에 있는 `interaction.user.roles` 사용 — 추가 API 요청 없음 |
| 실제 이동 | **로블록스로 직행하는 링크 버튼** — 중계 서버를 거치지 않음 |
| 열람 기록 | 응답을 보낸 **뒤** 백그라운드 처리 — 클릭 속도에 영향 없음 |

### 🧱 모듈 분리 원칙

`verify.py` · `link_guard.py` · `verify_db.py`는 **포인트 이코노미와 완전히 독립**되어 있습니다.

- `utils/database.py`(포인트 · 상점 · 뽑기 · 제보 · 블랙리스트)를 **전혀 import 하지 않습니다**.
- 포인트를 지급 · 차감하지 않고, `/로그`의 활동 기록에도 남기지 않습니다.
- MongoDB 컬렉션(`verify_settings`, `linkguard_settings`, `protected_links`,
  `link_clicks`, `link_watermarks`, `guarded_keys`)과
  로컬 JSON 파일(`data/verify_settings.json` 등)을 **별도로 사용**합니다.

따라서 이코노미 쪽 코드를 수정하거나 제거해도 인증 · 링크 보호는 그대로 동작합니다.
